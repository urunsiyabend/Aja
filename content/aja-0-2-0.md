Aja 0.2.0 brings richer content and better navigation while keeping the site
output static and dependency-free. This release requires Siyo 0.7.0.

## Reading aids

Every body heading gets a shareable permalink. The contents list links to those
headings, repeated titles receive unique IDs, and canonically equivalent
Unicode titles use the same base fragment. Code blocks never become headings.

Word counts and estimated reading time exclude fenced code. Previous and next
post links follow publication dates, not the homepage's weighted listing order.
Drafts and standalone pages do not enter that post sequence.

## Task lists

- [x] Write the generator in Siyo
- [x] Test the real command-line workflow
- [x] Preserve static asset bytes
- [ ] Add your own content and theme

Both ordered and unordered lists accept task markers. The generated checkboxes
are disabled indicators; this is not a browser-side task management system.

## Control the contents list

Use `toc: false` in a document's front matter to hide its contents list without
removing heading permalinks. Omit the key to keep the default enabled.

## Configuration diagnostics

Malformed site JSON now produces a readable error with the file and parser
reason. A failed configuration check exits non-zero before modifying output.

## Upgrade

Install Siyo 0.7.0, then run Aja's check and build commands. Existing custom
templates remain valid; add the new reading-aid placeholders to display the
features already included in the default theme.
