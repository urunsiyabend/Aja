# Find the right post

Aja 0.3.0 adds a [full-text search page](/search/) and a [monthly archive](/archive/).
Search covers titles, descriptions, tags and body text. Try searching for **draft previews**
or **Siyo**; share your results using the page’s query URL. Accent-insensitive matching
also finds Ürün when you type `urun`.

## Browse by month

Archive pages list published posts newest first, regardless of homepage weights.
The archive index shows a post count for each populated month; drafts and standalone
pages never enter the archive, even during a draft preview.

## Preview unpublished work

```sh
./aja check --drafts
./aja serve 4173 --drafts
```

The flag changes only the current invocation. Search, feeds and other preview
artifacts can include drafts: do not deploy preview output. Rebuild normally with
`include_drafts: false` before deployment.

## Safer generation

Content or static files cannot silently replace the new generated discovery pages.
`check` and `build` report those conflicts before existing output is removed.
Unknown CLI options and invalid ports now produce readable errors.

| Feature | Route or command |
| :--- | :--- |
| Full-text search | `/search/` |
| Monthly archive | `/archive/` |
| Draft validation | `aja check --drafts` |
| Draft preview | `aja serve --drafts` |

Siyo 0.7.0 remains the generator toolchain. Browser search is a small dependency-free
JavaScript enhancement; the archive also works without JavaScript.
